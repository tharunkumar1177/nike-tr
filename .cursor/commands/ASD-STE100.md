# ASD-STE100

Explain the selected text, or your last response if nothing is selected, in ASD-STE100 Simplified Technical English.

## Rules
- Keep sentences short: up to 20 words for instructions, 25 for descriptions.
- One instruction per sentence, action first.
- Use active voice and simple tenses.
- Use common words, one meaning per word.
- Keep technical terms, code names, and file paths unchanged.
- Apply these rules about 80% of the way. Readability wins over strict compliance.
